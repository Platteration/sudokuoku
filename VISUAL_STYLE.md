# Illustrated tabletop visual language

Keep the game readable and the interface simple. Use warm ivory (#f5f0e6) or deep ink (#19232d) behind opaque paper/panel surfaces, with muted sea-glass and amber accents. Use 8 / 12 / 16 point corner radii and the existing spacing rhythm. Body text stays in the platform sans-serif family; weight establishes hierarchy.

Depth is shallow: a crisp outline, one short lower edge, and one small upper-left highlight. Keep the board face-on and hit areas aligned to the grid. Anime influence belongs in bold silhouettes and restrained effects, with no extra decoration over selection, errors or phantom markers.

Preserve existing colour packs and accessibility settings. Color is supported by existing labels, rings and markers.

Before merging, inspect light/dark modes, a narrow phone layout, selected cells, shifts and the win state. Run the repository typecheck and existing tests.
