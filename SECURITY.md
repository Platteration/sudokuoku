# Security policy

## Reporting a vulnerability

Please report security issues privately rather than opening a public issue.

Use GitHub's private vulnerability reporting on this repository:
**Security → Report a vulnerability**. That opens a private advisory visible
only to the maintainers. Where the repository does not offer that button,
open an issue that says only that you have a security report and how to reach
you, and leave the details out of it; the website's
`/.well-known/security.txt` points at the issues for that reason.

Include what you need to make the problem reproducible: the affected version
or commit, the steps or input that trigger it, and what you observed. A proof
of concept helps but is not required.

This is a small project maintained in spare time, so there is no response-time
guarantee. Reports are read and acted on in order of severity.

## Scope

In scope: the code in this repository, including anything it does with input
that comes from outside it (files, share links, imported data, network
responses, user-supplied text rendered into a page).

On the website (the web build, `npm run build:web`) that includes:

- a way to run script, or load anything, that the Content Security Policy in
  `public/_headers` should forbid, or a request the site makes to anywhere at
  all (the policy's `connect-src` is `'none'`: the game has no network code);
- a challenge code, link or saved game that breaks the page for the next visit;
- hosting settings in `public/_headers`, `public/_redirects`, `public/.htaccess`
  or `deploy/nginx.conf` that are wrong or incomplete, such as a file served
  that is not part of the site.

Out of scope: vulnerabilities in third-party dependencies that are already
public and have an upstream fix, findings that require an attacker to already
control the device or account, and reports generated by a scanner with no
demonstrated impact. So is what a host that sends no response headers (GitHub
Pages) cannot enforce, and what another app on a shared origin can do to this
one's saved games: the README's Deploy section names both, and the remedy, a
host that sends headers and an origin of the site's own.
